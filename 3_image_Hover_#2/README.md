# Interactive Image Gallery (3D Hover Effect)

A clean and dynamic image gallery built with HTML and CSS. The goal of this project is to create engaging micro-interactions where images present themselves in a fan-like spread. 

### Features
- **3D Depth Hover Effect:** When hovered, an image straightening out (rotation returns to zero) and smoothly rising above the others.
- **Micro-interactions:** Showcases the power of pure CSS transitions and z-index manipulation to create interactive, responsive image stacks.

### Technologies Used
- HTML
- Vanilla CSS
