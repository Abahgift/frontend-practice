Voice mode

Comet Voice Mode is now smarter and faster. Powered by GPT Realtime 1.5, you can now use Voice Mode to ask about what you’re seeing, navigate the web by voice, and continue conversations seamlessly as you switch tabs. Start from the toolbar or use the keyboard shortcut (⌥⇧V on Mac / Alt+Shift+V on Windows).

What's new:

  • Screen awareness: Ask Comet about anything you’re seeing. No copying, pasting, or jumping between apps.
  • Navigate by voice: Open pages, move through sites, or take actions using your voice.
  • Context that stays with you: Switch tabs freely. Comet remembers where you left off so you don't lose your place.

Perplexity Computer

Perplexity Computer is a general-purpose digital worker that operates the same interfaces you do. Computer creates and executes entire workflows, capable of running for hours or even months.

What Computer does for you:

  • Background tasks and continuous monitoring: Set recurring tasks that Computer executes autonomously and persistently over time.
  • Parallel research and browser automation: Search the web, automate browser actions, extract data, and synthesize findings in a single workflow.
  • Connect tools and apps:Connect Gmail, Slack, Notion, Calendar, and hundreds of others.
  • Create and build: Create production-ready apps, websites, reports, and more.

Put Computer to work. Available now to Perplexity Max subscribers. Coming soon to Enterprise and Pro users.
