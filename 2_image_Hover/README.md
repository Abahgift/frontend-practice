# Premium Image Hover Interaction ✨

Okay, so I built this super sleek micro-interaction! It’s an elegant, pure CSS hover effect that perfectly matches a high-end design pattern I've been working on.

### What it does:
Instead of just a boring color change, when you hover over an option (like **Growth, Fun, Fitness, Community**), a highly polished specific image smoothly pops up right above it. Oh, and the icons also flawlessly cross-fade to their colored SVG counterparts while keeping a buttery-smooth 1.05x zoom effect! 

To top it off, all the other sibling options slightly dim out so your eyes can focus completely on the hovered pop-up, giving it a true 3D depth with its crisp drop-shadows.

### Tech Stack:
- Vanilla **HTML** & **CSS**
- No heavy Javascript! The smooth CSS interactions and animations are handled entirely via `transform`, `opacity`, `filter`, and custom bezier curves for optimal performance.

Loved working on the precision of the shadows and animation curves for this one to lock in that premium feel!

## Usage
Just open up the `index.html` file in your browser to check out the vibe.
