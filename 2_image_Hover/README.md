# Image Hover Interaction #1 

Okay, so I built this image hover micro-interaction using html and CSS hover effect.

### What it does:
When you hover over an option (like **Growth, Fun, Fitness, Community**), a specific image pops up right above it. The icons also cross-fade to their colored SVG counterparts while keeping a slight zoom effect! 

Also, all the other sibling options slightly dim out so the eyes can focus completely on the hovered pop-up, giving it a 3D depth with its drop-shadows.

### Tech Stack:
- Vanilla **HTML** & **CSS**
- The CSS interactions and animations are handled entirely via `transform`, `opacity`, `filter`, and custom bezier curves for optimal performance.
